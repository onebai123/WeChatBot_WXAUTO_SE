本项目是一个 LLM API 聚合与自动化调用工具。
项目用于 本地部署环境下的大语言模型调用、调度与消息处理。
本项目不提供任何内容服务，不对模型生成内容进行引导、编辑或推荐。
本项目 禁止接入微信、QQ 等腾讯系软件。

# 功能说明
1. 消息自动化处理模块
支持多会话并行处理
支持为不同会话配置独立的系统参数（Prompt 作为技术配置项）
2. 多模态输入解析
支持图片内容解析
支持表情包作为输入数据的一种形式
3. 输入结构化分析
对文本输入进行基础特征分析
根据输入类型返回预设的响应结构
4. 链接内容获取与摘要
自动解析消息中的 URL 并获取公开网页内容
5. 系统时间参数注入
向模型提供标准化时间信息
6. 消息调度与合并处理
支持多条输入合并后统一处理
支持程序级别的主动任务触发
7. Web 管理界面（WebUI）
用于程序启动、配置文件管理
支持 Prompt 作为系统参数进行维护
8. 上下文摘要与存储机制
可调用模型对历史输入进行摘要
摘要结果仅作为后续调用的上下文参数
9. 任务调度与提醒功能
支持基于时间规则的任务触发
示例：定时提醒、周期性任务
支持语音形式的系统通知
10. 联网信息获取支持
11. 语音输入支持（基于外部转写结果）
12. 程序自动更新机制
13. 指令式功能调用模块
14. 论坛功能
# 使用前准备
1. 请先安装 Python 与 pip（Python ≥ 3.8）
2. 用户需自行申请并配置第三方大模型 API
本项目支持多种 API 接入方式
